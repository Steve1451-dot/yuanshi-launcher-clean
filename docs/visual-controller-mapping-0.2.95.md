# 0.2.95：可视化手柄映射

入口不变：游戏内触摸悬浮球 → 手柄自定义映射。
原神、星铁、绝区零、终末地共用这套界面，各自保存配置。

## 界面与操作

- 在原来的映射列表左侧增加原创 Joy-Con 掌机正面及背面/肩键示意图。
  不下载官方图片、不使用光栅纹理，不需要在 SD 另放图包。
- 点击图上的 A/B/X/Y、L/R、ZL/ZR、L3/R3、加号或方向键，
  右侧直接进入对应实体按键的目标选择。图中央显示当前真实映射。
- 图上的描边高亮表示当前选择，亮色表示 UI 当前采到实体按下。
  这是本地输入显示，不是云端回执，也不记录逐按键日志。
- 方向键＋A 继续操作右侧列表；图中当前选择同步跟随列表焦点。
- 减号继续保留本地诊断，点击只提示并定位保留项，不允许误改。
- L3/R3 指按下摇杆；本版仍是按键映射，不增加摇杆轴互换。
- 背面是 ZL/ZR 肩键位置示意，不虚构 Joy-Con 不存在的背键。

拖动离开按键区域、多手指替换、开窗时已按住按键都不会直接提交映射。
点击示意图空白区域不关闭；点击两块面板之外或关闭按钮才返回。
目标选择、即时保存、保存失败保留旧配置、恢复默认的二次确认都沿用原策略。

布局和点击命中共用同一份几何数据，避免“看着按 A 实际选了别的键”。
标准 Switch 1280×720 下显示完整左右布局；窄窗口保留原列表，不缩出难以点击的热点。

## 不改变的部分

映射文件格式和路径不变，已保存的四游戏配置可直接恢复，原神默认 AB/XY 互换保留。
本地菜单和退出快捷键不变。未改登录、排队、串流网络、解码、音频或原生体感协议。
0.2.94 安卓终端＋PS5 实验开关保留，仍默认关闭，仍不是体感生效证明。

示意图只在映射面板打开时绘制；不增加游戏画面常驻开销、线程、文件轮询或图片解码。
