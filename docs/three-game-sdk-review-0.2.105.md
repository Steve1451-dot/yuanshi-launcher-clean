# 0.2.105：原神、终末地、崩铁的 SDK 对照与有界恢复

日期：2026-11-03（Asia/Singapore）。这是 0.2.104 可玩基线上的小范围修补，
不是三个游戏均已完成在线验收的声明。本轮没有启动模拟器或额外云端会话。

## 原神：修正 SDK 本地缓存的回包语义

核对本地已保存的官方网页实现：

- `reference/web/ys/web.b959658b.js`
- `reference/web/sr/web.4f0790db.js`

两者的 `cloudSetData` 都替换整份缓存；`cloudGetData` 的普通键都使用
`storedValue || ""`，`account_id` 则走单独的账号字段。原生实现此前仅排除
`null`，会把 `false` 和数值零原样返回，与网页 SDK 不一致。

本轮保留整份替换、账号特例及已有结构化值编码，只将 `null`、`false`、正负零
按官方行为返回空字符串。空数组、空对象仍是真值，不错误清空。此修正共用于
原神和崩铁；跨 app_id 4/8/12 的回归也覆盖绝区零，避免共享桥串用元数据。

另核对原神 Android 7.1.0-3 的 `K5/a.java` 与
`gamecloud/playcenter/third/BaseSdkHolder.java`：前者定义相同的缓存命令，后者
将缓存命令和透传数据列入日志排除名单。常量本身不能证明安卓缓存实现等同于
网页，上述具体真假值语义以已读取的 H5 实现为依据；原生也不增加缓存正文日志。

这不是对游戏远端设置持久化能力的承诺。不把 SDK 缓存写入明文文件，不改变
已有登录 vault，不记录缓存值或账号数据。

## 共享稳定性：限制 SDK JSON 深度

原来 SDK 外层已有 256 KiB 大小上限，但该上限不能阻止极深的容器嵌套。
新增 `mihoyo/sdk_json.hpp`，在构建 JSON DOM 前做非递归、无分配的扫描：

- 上限仍为 256 KiB，容器最多 64 层；引号和转义字符串中的括号不计入层数。
- 语法合法性仍由 JSON 解析器判断；预扫描不替代语法校验。
- 外层解密消息、字符串参数、包装调用、字符串缓存和内部回包追踪都使用同一入口。
- 非 JSON 的普通参数字符串保留原来的字符串回退，不改变协议含义。
- 超限外层消息使用原有安全解析失败事件，不输出正文。下一条正常消息仍可处理。

测试包含 64/65 层边界、4096 层拒绝、256 KiB 边界、转义字符串，以及经真实
AES/可靠消息入口送入的异常消息后再处理正常 `Init`。此处只限制控制消息，
不在每个视频帧上增加扫描。

## 终末地：旧手柄状态不能在新状态确认后重发

继续对照本地 Android 1.6.0 的 JADX 输出：

- `cloudgame/bridge/CloudBridge.java`
- `cloudgame/gamepad/GamepadManager.java`

官方 `GetGamepad` / `GamepadChange` 查询读取当前设备槽位，走已有
`replyOnGetGamepad`。当前原生回调名无需修改，实际确定的问题在可靠重试队列：
连接、断开、再连接三条通知可同时待确认；即使最新连接已确认，旧断开仍可能
重发，使游戏回退到过时状态。

先添加回归用例，在旧实现复现失败，再修补为：

- 只合并主动发送的全局 `GamepadChange` 状态快照，始终保留最新一条。
- 新快照有独立消息索引；旧消息的延迟确认不能确认新状态。
- 队列满时可替换旧快照，但不能挤掉查询、启动或登录回包。
- 不把合并计作成功确认或超时；16 条队列、15 秒期限与原重试间隔不变。

Android SDK 与 WebRTC 两种桥配置均覆盖了快速断开/重连、过期 ACK 和满队列
替换测试。没有改变 Joy-Con 来源选择、Xbox 输入格式或用户映射。

## 崩铁：指纹来源仍需证明，不能声称修好了 1001_2

本轮继续阅读本地 Android 4.6.0 的反编译产物，而非重新索取或整包重复解包：

- `platform/sdk/devicefp/FingerprintService.java`：`getExtList` 和 `getFp` 的入口，
  请求字段包括 device_id、seed_id、seed_time、platform、device_fp、app_name、ext_fields。
- `AbstractDeviceUniqueIdentifier.java`、`DeviceFingerprintSharedPreferences.java`：
  服务获取、缓存和失败回退路径。
- `combo/interf/IInfoModule.java` 及网页 `combo-web.7d4a7ffa.js`：宿主指纹回调契约。

结论：原生本地 13 位 FNV 派生值仍不能当作已验证的官方服务指纹；也不能仅由
安卓实现推断所有网页终端必须伪装安卓。没有向真实指纹服务提交请求，没有把
账号/设备数据加入日志，没有同时改终端身份、CPS 和指纹来混淆变量。

对现有 `libtransport_engine.so` / `libclient_core_jni.so` 也进行了有界、只读的
原生字符串候选检查；所选 `.rodata` 模式没有给出所需精确命中。这不是调用链
反汇编证明，更不能据此认定某协议不存在。

崩铁已获得本版共享缓存回包修正和解析保护；0.2.104 的安全 `1001_2` 固定标记
采集仍保留。但这些不等于该入场错误已解决。后续应做单独的崩铁会话协议对照，
确认错误仍存在的阶段及官方宿主回包来源，不让原神、终末地承担未经验证的改动。

## 保持不变

0.2.104 的透明状态窗、精简触摸菜单、减号地图、L3+R3 长按诊断、每游戏独立
画质配置均保留。原神位置键位与物理 ZL 体感不改，Xbox 默认身份不改；最低
画质/60 帧默认请求不改，已保存配置不覆盖。音视频、软硬解码和登录保存主线
均未改动。本轮没有把 APK、官方网页源码或凭据打进发布目录。
