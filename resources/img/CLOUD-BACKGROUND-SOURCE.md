# Archived official-art provenance (not distributed since 0.2.91)

The files below are retained in the source working tree as historical inputs.
New NRO builds explicitly exclude these four images and this provenance file
from RomFS. The homepage now reads optional user images from
`AppHomePath()/backgrounds/`, with original procedural geometric artwork as
fallback. The optional original PNG pack is generated by
`scripts/generate-original-backgrounds.ps1`; it contains none of the following
official images. The historical notes below describe the old packaging only.

One official image per game, shipped in the NRO ROMFS and shown behind the
main page. Only the selected game's texture is loaded (a switch deletes the
old NVG image before creating the new one).
