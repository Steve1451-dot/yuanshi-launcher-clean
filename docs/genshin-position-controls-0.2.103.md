# 0.2.103：原神本地位置方案 + 实体 ZL 体感

日期：2026-11-02。只改原神客户端的本地输入转换，不改云端游戏键位、
登录、手柄身份、RTC、解码或画质设置。其他游戏默认与配置保持不变。

本文件取代待检查报告中的“普攻长按 200ms 触发体感”提议。用户随后让客户端
自行选择可靠方案，本版保留已验证的实体 ZL 体感，不增加普攻延迟或长按计时。

## 默认实际按键

| Switch 实体按键 | 功能（云端游戏保持原始 Xbox 键位） | 发出的 Xbox 输入 |
|---|---|---|
| R | 普攻／长按蓄力 | B |
| ZR | 元素战技 | RT |
| X，上侧 | 元素爆发 | Y |
| A，右侧 | 冲刺 | RB |
| B，下侧 | 跳跃 | A |
| Y，左侧 | 拾取／交互 | X |
| ZL | 原瞄准键 + 本地体感开关 | LT + 合成的右摇杆 |
| L | 默认快捷轮盘 | LB |

Xbox 身份不变；视频中的按钮提示不会自动改成 Switch 字母。
若云端游戏已经自定义过按键，本表不代表那个远端自定义配置。

## 轮盘与菜单保护

- 新方案的 R→普攻、右 A→冲刺互换，只在普通战斗映射中采用。
- 实体 L 保持原功能。L 按住时恢复 R/右 A 的原生位置输入：L+右 A 发 LB+B
  使用原来的道具组合；L+R 发 LB+RB，不会误吃成 LB+B。
- 轮盘保护只修正该交换对，不抹掉无关自定义方向键等映射。只有仍采用
  右 A→RB、R→B、L→LB 的原神配置才启用这条保护。
- 原神取消 L+R 打开客户端浮球的旧快捷键，浮球使用触摸打开。
  其他游戏快捷键未改。
- 不猜测云端当前是否在菜单。需要原生菜单操作时，使用：
  浮球 → 手柄自定义映射 → 上一页（第 3 页“体感与操作模式”）→
  “操作：战斗映射（点此切原生菜单导航）”。
- 原生菜单导航按物理位置透传，暂时绕过本地战斗映射，并停止体感。
  左下角显示“原生菜单导航中 · 体感暂停”。同一选项可切回战斗。
- 模式切换产生输入交接/中立报告，已有本地浮球/日志捕获和松键保护仍保留。
- 导航模式只在本次串流生效，每次新串流从战斗开始。它不改写用户的战斗键位。

## 体感

默认继续由实体 ZL 触发，R 普攻本身不触发体感。保留 0.2.102 修正的水平方向、
纵向行为、灵敏度、噪声过滤、限幅和实体右摇杆优先规则。
L 轮盘、原生菜单导航、本地 UI 捕获、输入交接及合成的进入/继续按键期间停用体感。
导航和轮盘的暂停也覆盖手动选择的“始终启用”。
本地行为不依赖云端启用原生 IMU；不声称自动识别武器或读取到游戏瞄准状态。

## 本地配置兼容

配置版本提升为 `CGNX-PAD 4`，字段数量未改变。它标记新默认已确认，避免下一次
启动又覆盖用户后来明确选择的旧布局。支持读取版本 1/2/3/4。

- 仅原神旧版已知默认（旧同字母表、早期原生位置表）迁移到新位置方案。
- 真正自定义目标表、灵敏度、版本 2/3 已明确关闭的体感等选择保留。
- 合法旧主文件升级后尝试原子保存；保存失败不声称持久化，当前会话使用内存值。
- 若仅备份文件有效，内存兼容恢复但不为自动升级覆盖唯一有效的备份。
- 原神已经保存自定义表的用户如想启用本方案，可在同一映射页“恢复本游戏默认
  配置”连续确认两次。不会删除登录文件或其他游戏的映射文件。

## 验证范围

主机测试包括实际输入编码/生产 Session 发送端，非真实云会话：

- 遍历全部 65,536 种按钮状态，核对战斗、轮盘、原生导航与其他游戏隔离。
- 单独核对 R/B、A/RB、B/A、X/Y、Y/X，及 L+R 不触发道具、L+右 A 保留道具组合。
- 自定义方向键在轮盘保护中仍保留；完整中立帧释放旧按键。
- ZL 开/关、R 单独按、轮盘与导航暂停，包括“始终启用”仍暂停。
- 配置版本兼容、默认迁移、自定义保护、无效格式、备份恢复与保存失败。
- 编辑器模式切换不修改/保存战斗表，不泄漏到其他游戏；中英文绘制和翻译。
- 保留合成进入/继续输入、默认画质/帧率与解码偏好相关回归检查。

完整 devkitPro Switch 构建用于检查 NRO。没有用 yuzu/真实 Switch 进行本次在线
游戏操作，不把离线传输测试或构建成功称作实机验收。
