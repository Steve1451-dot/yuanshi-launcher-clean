# yuanshi launcher 0.2.112 alpha

原神默认使用游戏原生手柄直通，键位交给游戏内设置处理。操作模式保存在 SD，
下次进入继续使用；悬浮球 → 手柄设置 → 体感与操作模式可切回原有本地映射。

- 原生模式绕过本地战斗按键重排、L 轮盘组合特例与体感转右摇杆。
- 原生手柄页显示标准按钮，不显示推测的游戏动作，也不允许误改本地键位表。
- 切换模式先保存，成功后发送中立输入再应用，保存失败继续旧模式。
- 界面区分等待云端手柄模式和真实回执；回执不代表游戏内键位已保存。
- 修复诊断未启用时，手柄模式回包调用空日志回调的异常。
- 其他游戏的输入配置保持各自设置；之前 ys/zmd 的通用弱网恢复改动继续保留。

本次实际下载并分析了官方云原神 7.2.0 APK。协议证据与限制见
[原生手柄调查记录](https://github.com/Steve1451-dot/yuanshi-launcher-ns/blob/main/docs/genshin-native-gamepad-7.2.0-2026-11-07.md)。
尚未发现可确认的直接上传动作绑定表接口，游戏内键位能否跨云端实例保留需要实机验证。
本版不宣称已经实现云端永久改键，也未进行新的登录或实机游玩验证。

源码版本、CMake/NACP、打包默认值均从 app_version.hpp 读取。
原生版随包的 HOME 快捷入口使用同一 CMake 版本；旧 OpenNOW 安装器不在原生 RomFS 内。
安装路径仍为 `sdmc:/switch/yuanshi-launcher/yuanshi-launcher.nro`。
包中不含 APK、厂商反编译代码或个人运行数据。
